Release notes

What changed in each release.

The ontology, tools and Architect are versioned together under semantic versioning. Before 1.0 a change that breaks a model, a command or a setting raises the minor number; a fix or an addition that breaks nothing raises the patch. Each release is tagged in the repositories, so the version a model was written against can always be checked out.

Breaking changes

Ontology

A rule traces to a clause by a dependency

A rule's trace to the clause it enforces was a ref enforces member. It is now #EnforcesClause dependency from <Rule> to <clause>, <clause>;, written beside the rule. A rule may name several clauses or none. To move: replace each ref enforces : StandardClause[1..*] = a.b.c; with the dependency, spelling the clause with :: and importing memo_artifacts_standards_traceability::EnforcesClause. Ontology 0.13.x remains tagged pre-typed-rule-clause-relation.

Tools

Commands split between memo and memo-architect

memo compiles, validates, packs and checks the toolchain; everything else, including init, is memo-architect. A retired command exits with an error naming its replacement. memo package is replaced by memo pack (a SysAnd KPAR) and memo-architect import kpar.

Tools · Architect

The compiler is named by the project

A project names its compiler with toolchain.compiler. A person can override it for themselves in Architect or with memo-architect config set compiler; tool paths are found automatically and are rejected in a checked-in project file.

Additions

Ontology · Tools

Rule obligation

Every rule states required, recommended or bestPractice. A rule that states no severity takes error, warning or info from it. Rules that trace to a clause start required; the rest start recommended. List by obligation with memo validate --rules --rules-obligation required.

Tools

Faster edits, a smaller handoff

Stage 1 converts only the documents an edit reached and stores them compressed. With OpenSysML 0.9.3 or later, the compact API JSON format is used where the service offers it.
